# 我做了一个给 ChatGPT / Claude / Gemini 用的极简划词词典，也把 AI 二次开发说明一起开源了

我最近有一个很小的痛点。

我平时会大量用 ChatGPT、Claude 之类的 AI。它们回答中文问题的时候，经常会夹一些英文。有时候我其实大概能看懂整句话，只是不认识其中一个词；有时候是一小句话没看懂。

为了这么一点东西去开沉浸式翻译或者做整页翻译，我一直觉得很重，也很麻烦。

所以我让 Codex 给我做了一个很小的 Chrome 扩展，叫 Selection Dictionary。

现在的效果很简单：

双击或者划一个英文单词，会直接显示中文释义和音标；划一句话或者一小段，会调用 Chrome 自带的本地翻译；点一下喇叭可以直接听英文发音。

查单词走的是本地词典，不需要 API；项目也没有账号、自己的服务器或者分析统计。对我来说最重要的是，它非常快，而且只解决我真正需要的这一件事。

项目在这里：

https://github.com/Zhangsfish/selection-dictionary

我把它放出来，主要不是想把它做成一个产品，也不太在意 star、点赞或者用户数。

我现在越来越觉得，AI coding agent 出来以后，很多这种很小、很个人的需求，软件的生产方式可能会变。

以前你有一个需求，要么去找一个现成产品忍受它多余的功能，要么自己从头开发。

以后可能更像是：你告诉 AI 你想要什么，它先去 GitHub 和网上找有没有已经解决了 70%–90% 的东西，然后在那个基础上把剩下的一点改掉。

所以我除了把源码放上去，还专门整理了 AGENTS.md、ADAPTATION_GUIDE.md、架构说明、测试和验证记录。目的就是让下一个 ChatGPT、Codex、Claude Code 之类的 coding agent 拿到这个 repo 后，不需要重新研究一遍划词监听、弹窗、并发取消、本地词典、浏览器测试这些已经解决的问题。

如果你刚好和我有完全一样的问题，可以直接用。

如果你的需求只和我差一点，比如你想换成日语、支持别的网站、换词典、改 UI，或者干脆做成另一个类似的小工具，我更推荐你不要从头做：

直接把这个 GitHub 链接丢给你的 AI，告诉它在这个项目上改。

能少重新解决一点已经解决过的问题，就少烧一点 token。
