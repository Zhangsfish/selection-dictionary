Review date: 2026-09-16.

This file records the current rules used to decide where the frozen canonical announcement can be posted without disguising AI-assisted copy, changing its story, or turning distribution into spam.

## LINUX DO

- Current open-source promotion instructions: https://linux.do/t/topic/1776670/1
- Current community invitation/rule document linked by the forum: https://linux.do/uploads/short-url/4tXZy7oHnCn40K8rDvLPRhoxAM8.pdf
- The promotion workflow requires the `#开源推广` tag, a mandatory declaration, a completely open-source project, and recognition/backlink treatment for LINUX DO. AI-generated or AI-polished promotional material must be shown as screenshots. The broader community document also rejects AI-written/polished promotion copy and cross-platform copy/paste.
- Decision: **Blocked**. The required screenshot/template/backlink treatment materially conflicts with the frozen, machine-readable, same-story Step 4B workflow.

- `分享创造` welcomes independent developers sharing new work; the canonical post fits that node better than the commercial `推广` node.
- Decision: **Blocked** because the available account still requires an invitation code before posting. No rule-avoidance attempt was made.

## Reddit / r/chrome_extensions

- Community page and rules: https://www.reddit.com/r/chrome_extensions/
- Reddit spam policy: https://support.reddithelp.com/hc/en-us/articles/360043504051-Spam
- The community allows Chrome-extension discussion and provides a `Self Promotion` flair. Its rules prohibit spam, clickbait, piracy, NSFW material, and vote brigading. Reddit's site-wide policy prohibits repetitive or mass unsolicited promotion and generative-AI spam, but does not prohibit one authentic, relevant post.
- Decision: **Prepared** as a single targeted English post with the required flair. No engagement or vote solicitation is planned.

## Tencent Cloud Developer Community

- Content review guidance: https://cloud.tencent.com/developer/article/2369320
- Community rules entry: https://cloud.tencent.com/developer/article/1006434
- The review guidance favors original, useful technical content, discourages large amounts of AI-generated content, and rejects hard advertising or traffic-driving material. The frozen post is a project announcement with an outbound repository link and reuse invitation rather than a substantial technical tutorial.
- Decision: **Human-writing-required**. A future article should be written by the user around real engineering details, measured latency, local-first architecture, and reproducible browser verification. It should link the repository only where the technical narrative supports it.
